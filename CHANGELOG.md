## Rainax DocScan v1.1.0
- New home screen: dark theme, search bar, tool grid (Smart Scan, Merge PDF, Import Images, Import Files, ID Cards, Extract Text, Sign, All), Recents list with Share / Save as PDF / View buttons, camera button.
- Bottom tabs: Home, All Documents, Tools, Me.
- New: import photos as a PDF, import existing PDF files, Extract Text from any image, Save as PDF to Downloads/Rainax DocScan.
- Install: download the .apk below, open it on your phone and allow "install from unknown sources". If you already have an older build installed, uninstall it first only if Android refuses to update.
